## 1. Evaluación continua de su entorno de AWS

Para mejorar la seguridad, la optimización de costos, el rendimiento y la resiliencia

### 1.1 Trusted Advisor

![Trusted Advisor](/icons/aws-trusted-advisor.svg)

**AWS Trusted Advisor** es un servicio de AWS que analiza continuamente el entorno de una cuenta y proporciona recomendaciones para optimizar los recursos y seguir las prácticas recomendadas de AWS. Su objetivo es ayudar a identificar oportunidades de mejora relacionadas con la seguridad, rendimiento, disponibilidad, optimización de costos y límites de servicio.

**Principales categorías**

Trusted Advisor proporciona recomendaciones en áreas como:

- **Optimización de costos**: identifica oportunidades para reducir gastos innecesarios.
- **Seguridad**: detecta configuraciones que podrían representar riesgos de seguridad.
- **Rendimiento**: busca oportunidades para mejorar el rendimiento de los recursos.
- **Tolerancia a errores**: ayuda a identificar configuraciones que podrían afectar la disponibilidad.
- **Límites de servicio**: permite conocer el uso de determinados límites de AWS y anticiparse a posibles problemas.

>**Trusted Advisor** ayuda a las organizaciones a reducir costos, mejorar la seguridad, aumentar el rendimiento y la disponibilidad, y mantener un entorno AWS más eficiente y alineado con las buenas prácticas.

Es extremadamente importante optimizar las implementaciones en la nube a gran escala, y no es algo que se haga una sola vez. Debe buscar maneras de optimizar los costos, el rendimiento, la seguridad y la resiliencia. Con AWS Trusted Advisor, puede evaluar de forma continua su entorno de AWS mediante comprobaciones de prácticas recomendadas en varias categorías. Todos los planes de AWS Support incluyen acceso a docenas de comprobaciones de Trusted Advisor. Con Business Support y otros planes avanzados, puede beneficiarse de cientos de comprobaciones.

**Beneficios**

Trusted Advisor le ayuda a alinearse con las prácticas recomendadas de AWS, priorizar las recomendaciones y optimizar sus recursos de AWS a escala.

**Casos de uso**

Se puede usar para optimizar el costo, la eficiencia y la seguridad, mejorar el rendimiento, y realizar un seguimiento de los límites de servicio.

![Evaluación continua de su entorno de AWS](/aws/monitoreo/monitoreo-aws-trusted-advisor.png)

Aunque **Trusted Advisor** realiza comprobaciones con el fin de optimizar la seguridad, es posible que necesite ayuda para comprobar los permisos detallados de AWS Identity and Access Management (IAM). El analizador de acceso de IAM puede ayudarle a cumplir sus objetivos de acceso con privilegios mínimos en su entorno de AWS.

### 1.2 Analizador de acceso de IAM

![Analizador de acceso de IAM](/icons/iam-access-analyzer.jpg)

El **analizador de acceso de IAM** ofrece funciones para establecer, verificar y refinar los permisos mediante el análisis del acceso externo y la validación de que sus políticas coincidan con los estándares de seguridad corporativos.

**Beneficios**

El analizador de acceso de IAM ofrece beneficios como refinar los permisos, validar las políticas de IAM, ayudarle a cumplir sus objetivos de privilegios mínimos y automatizar las revisiones de las políticas de IAM.

**Casos de uso**

Se puede usar para establecer permisos detallados, verificar quién puede acceder a qué, corregir el acceso no utilizado y refinar y eliminar el acceso amplio.
