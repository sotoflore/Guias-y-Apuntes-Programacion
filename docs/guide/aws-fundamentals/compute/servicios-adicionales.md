# Servicios de computación adicionales

AWS ofrece servicios personalizados para necesidades específicas, como optimizar la implementación de aplicaciones web, administrar cargas de trabajo por lotes, proporcionar servidores virtuales y ampliar la infraestructura de nube a los centros de datos en las instalaciones.

## 1. Elastic Beanstalk

![elastic Beanstalk](/icons/amazon-elastic-beanstalk.svg)

**Elastic Beanstalk** es un servicio completamente administrado que optimiza la implementación, la administración y el escalado de aplicaciones web. Los desarrolladores pueden cargar su código y Elastic Beanstalk administra de manera automática el aprovisionamiento de la infraestructura, el escalado, el equilibrio de carga y la supervisión del estado de la aplicación. Es compatible con varios lenguajes y marcos de trabajo de programación, como Java, .NET, Python, Node.js, Docker y más. Proporciona un control total sobre los recursos subyacentes de AWS y, al mismo tiempo, automatiza muchas tareas operativas.

>**Ideal para**:  implementar y administrar aplicaciones web, API de RESTful, servicios de backend móviles y arquitecturas de microservicios, con escalado automatizado y administración simplificada de la infraestructura.

## 2. AWS Batch

![AWS Batch](/icons/aws-batch.svg)

**AWS Batch** es un servicio completamente administrado que se puede usar para ejecutar cargas de trabajo de computación por lotes en AWS. Programa, administra y escala automáticamente los recursos de computación para los trabajos por lotes, lo que optimiza la asignación de recursos según los requisitos del trabajo.

>**Ideal para**: procesar cargas de trabajo paralelas a gran escala en áreas como la computación científica, el análisis de riesgos financieros, la transcodificación de medios, el procesamiento de macrodatos, el entrenamiento de machine learning y la investigación genómica.

## 3. Lightsail

![Lightsail](/icons/amazon-lightsail.svg)

**Amazon Lightsail** es un servicio de nube que ofrece servidores privados virtuales (virtual private servers, VPS), almacenamiento, bases de datos y redes a un precio mensual predecible. Es ideal para pequeñas empresas, cargas de trabajo básicas y desarrolladores que buscan una experiencia de AWS sencilla sin la complejidad que implica la Consola de administración de AWS completa.

>**Ideal para**: aplicaciones web básicas, sitios web con poco tráfico, entornos de desarrollo y pruebas, sitios web de pequeñas empresas, blogs y servicios de aprendizaje en la nube.

## 4. Outposts

![Outposts](/icons/aws-outposts.svg)

**AWS Outposts** es una solución en la nube híbrida completamente administrada que extiende la infraestructura y los servicios de AWS a los centros de datos en las instalaciones. Proporciona una experiencia coherente entre las instalaciones y la nube de AWS, y ofrece componentes de computación, almacenamiento y redes.

>**Ideal para**: aplicaciones de baja latencia, procesamiento de datos en ubicaciones remotas, migración y modernización de aplicaciones heredadas y cumplimiento de los requisitos de residencia de datos o conformidad normativa.
