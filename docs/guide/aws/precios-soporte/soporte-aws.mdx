# AWS Support

**AWS Support** es el conjunto de servicios y recursos de asistencia que ofrece Amazon Web Services para ayudar a los clientes a resolver problemas técnicos, optimizar sus aplicaciones, mejorar la seguridad y obtener orientación sobre el uso de AWS.

AWS Support proporciona diferentes niveles de soporte, diseñados para adaptarse a las necesidades de cada organización. Dependiendo del plan contratado, los clientes pueden acceder a distintos niveles de soporte técnico, tiempos de respuesta, orientación arquitectónica y herramientas de gestión.

Además del soporte técnico, AWS proporciona recursos de autoservicio, documentación, artículos técnicos, foros, AWS re:Post, herramientas de diagnóstico y servicios especializados que permiten solucionar problemas y aprender a utilizar correctamente la plataforma.

**¿Por qué es importante?**

Para una organización, AWS Support puede ayudar a:

- Resolver problemas técnicos relacionados con servicios de AWS.
- -Mejorar la seguridad y detectar posibles problemas.
- Optimizar arquitecturas siguiendo buenas prácticas.
- Optimizar costos y detectar oportunidades de ahorro.
- Mejorar el rendimiento de las aplicaciones.
- Obtener orientación y recursos para utilizar AWS correctamente.

>**AWS Support** ofrece diferentes niveles de asistencia según las necesidades del cliente. No todos los planes proporcionan el mismo nivel de soporte, tiempos de respuesta o acceso a orientación especializada.

## 1. Tipos de soporte de AWS

![Tipos de soporte de AWS](/aws/precio-soporte/soporte-tipos-soporte.png)

AWS ofrece una gama de planes de soporte diseñados para satisfacer las necesidades de los diferentes clientes, desde los que acaban de empezar hasta las grandes empresas con requisitos complejos. Cada plan se basa en el anterior y agrega herramientas más avanzadas, soporte personalizado y tiempos de respuesta más rápidos para ayudarle a aprovechar al máximo su experiencia con AWS.

### 1.1 Basic Support

Es el nivel básico y está disponible sin costo adicional para todos los clientes de AWS. Incluye recursos de autoservicio para que el cliente pueda resolver dudas y supervisar el estado de AWS. Incluye:

- Acceso a documentación de AWS.
- AWS re:Post.
- AWS Health Dashboard.
- Información sobre el estado de los servicios.
- Recursos de autoservicio.

**No incluye**

- Soporte técnico individualizado mediante casos de soporte.

>**Basic** = recursos de autoservicio (me ayudo yo mismo).

### 1.2 Developer Support

Está pensado principalmente para desarrolladores que están creando y probando aplicaciones en AWS. A diferencia de Basic, permite obtener asistencia técnica. Incluye:

- Soporte técnico.
- Orientación sobre cómo utilizar los servicios de AWS.
- Acceso a soporte mediante casos.
- Ayuda durante el desarrollo y las pruebas.

**Por ejemplo**:

Estás desarrollando una aplicación que utiliza Amazon S3 y tienes un problema con la configuración. Puedes recurrir al soporte para recibir orientación.

>**Developer** = estoy desarrollando una aplicación.

### 1.3 Business Support

Está pensado para empresas que tienen cargas de trabajo en producción y necesitan soporte técnico más completo (asistencia técnica individualizada). Proporciona **soporte 24/7** para problemas técnicos. Puede ayudar con:

- Problemas de producción.
- Configuración de servicios.
- Orientación sobre AWS.
- Creación de casos de soporte.
- Orientación y solución sobre problemas técnicos.
- Acceso a herramientas y capacidades adicionales de soporte.
- Orientación para mejorar el uso de los servicios de AWS.

Es apropiado cuando una empresa necesita algo más que documentación y autoservicio. **Por ejemplo**:

Una empresa tiene una aplicación en producción utilizando Amazon EC2, Amazon RDS y Amazon S3, y la aplicación presenta un problema. Business Support proporciona asistencia técnica para investigar el problema.

>**Business** = soporte técnico 24/7 para cargas de trabajo empresariales (mi aplicación ya está en producción).

### 1.4 Enterprise On-Ramp Support

Este nivel está pensado para organizaciones que necesitan soporte empresarial más avanzado, pero que todavía no requieren todas las capacidades del nivel Enterprise Support. Es una especie de puente entre Business y Enterprise. Incluye:

- Soporte técnico 24/7.
- Orientación técnica.
- Soporte para cargas de trabajo importantes.
- Mayor enfoque proactivo.
- Acceso a recursos especializados.
- Un nivel de acompañamiento mayor que Business.

Una característica importante es que proporciona acceso a **TAMs** (Technical Account Managers) de forma pool-based, es decir, como un **equipo compartido**, en lugar de tener necesariamente un TAM dedicado exclusivamente a la organización.

>**Enterprise On-Ramp** = quiero soporte empresarial avanzado, pero no necesito todo Enterprise.

### 1.5 Enterprise Support

Es el nivel más completo de estos planes tradicionales y está orientado a organizaciones con cargas de trabajo críticas para el negocio. Además de las capacidades de soporte técnico, proporciona una relación más cercana con AWS y orientación especializada. Incluye:

- Soporte técnico 24/7.
- Orientación proactiva.
- Recomendaciones para mejorar la operación de AWS.
- Revisión y recomendaciones sobre arquitectura.
- Ayuda para optimización.
- Orientación sobre seguridad, rendimiento y operaciones.
- Soporte para aplicaciones y cargas de trabajo críticas.

>**Enterprise** = negocio crítico + soporte personalizado (Mi negocio es crítico y necesito orientación especializada).

:::info ¿Qué es un TAM?
Technical Account Manager (Administrador Técnico de Cuenta - TAM), Es un especialista de AWS que ayuda a una organización a:

- Planificar su estrategia técnica.
- Identificar riesgos.
- Optimizar su infraestructura.
- Mejorar la arquitectura.
- Prepararse para eventos importantes.
- Aprovechar mejor AWS.

>Los planes **Enterprise On-Ramp** y **Enterprise Support** incluyen un administrador técnico de cuenta (TAM). El TAM actúa como su contacto principal en AWS y le ofrece orientación experta sobre el uso de los servicios de AWS, la optimización de las arquitecturas, la administración de los costos y la conexión con los programas y los expertos de AWS. **Por ejemplo**, si está creando una aplicación con varios servicios de AWS, su TAM puede asesorarle sobre el mejor enfoque de integración.

:::

### 1.6 AWS Unified Operations

Es una opción orientada a organizaciones que necesitan una experiencia más amplia de operaciones y soporte, integrando capacidades de soporte técnico, gestión y operaciones de AWS.

Está pensado para clientes con entornos complejos y necesidades importantes de operación a escala.

>**Unified Operations** = Necesito soporte y operaciones integrales a gran escala (entornos complejos).

## 2. Recursos adicionales para el traspaso a la nube

Además de los planes de AWS Support, AWS también proporciona acceso a otros equipos, recursos y documentación que puede utilizar para respaldar su traspaso a la nube. 

![Recursos adicionales](/aws/precio-soporte/soporte-recursos-adicionales.png)

1. **AWS re:Post**. Es una plataforma de preguntas y respuestas impulsada por la comunidad en la que los usuarios pueden buscar ayuda, compartir conocimientos y encontrar soluciones relacionadas con los servicios y las tecnologías de AWS. AWS re:Post también alberga el AWS Knowledge Center. El AWS Knowledge Center contiene artículos y videos sobre las preguntas y solicitudes más frecuentes de los clientes de AWS.

2. **Centro de confianza y seguridad de AWS**. Proporciona información sobre cómo denunciar actividades o contenidos en AWS que sospeche que son abusivos.

3. **Arquitectos de soluciones de AWS**. Para los clientes de los planes Business y Enterprise Support, los arquitectos de soluciones (solutions architects, SA) de AWS brindan orientación respecto a la arquitectura, recomendaciones de prácticas recomendadas y ayuda para diseñar aplicaciones escalables y seguras.

4. **AWS Professional Services**. Son servicios de consultoría que ofrecen un soporte más profundo basado en proyectos. Ayudan con migraciones complejas, auditorías de seguridad, ajustes de rendimiento y más.

5. **Autoayuda en AWS**. AWS también proporciona una amplia documentación y recursos de autoayuda que puede utilizar para investigar, responder a una pregunta o solucionar un problema. La documentación incluye guías del usuario para los servicios de AWS, guías de SDK, publicaciones de blog y documentos técnicos sobre soluciones específicas.

## 3. AWS Marketplace y socios de AWS

## 3.1 AWS Marketplace

**AWS Marketplace** es un catálogo digital que incluye miles de listados de software de proveedores de software independientes. Puede utilizar AWS Marketplace para buscar, probar y comprar un software que se ejecuta en AWS. Para cada listado de AWS Marketplace, puede acceder a información detallada sobre las opciones de precios y las reseñas de otros clientes de AWS. Entre las soluciones y los servicios que se ofrecen en AWS Marketplace se incluyen los siguientes:

**Software como servicio (SaaS)**:

- Aplicaciones empresariales, como herramientas de administración de proyectos
- Herramientas de marketing, como las plataformas de interacción con los clientes
- Herramientas de colaboración, como los servicios de intercambio de archivos

**Machine Learning (ML) e IA**:

- Modelos prediseñados para el reconocimiento de imágenes, el procesamiento de lenguaje natural y más
- Algoritmos de ML para entrenar modelos personalizados

**Datos y análisis**:

- Plataformas de inteligencia empresarial para visualización e informes
- Herramientas de integración de datos

También puede explorar soluciones de software por sector y caso de uso. **Por ejemplo**, suponga que su empresa corresponde al sector de sanidad. En AWS Marketplace, puede revisar los casos de uso que el software le ayuda a abordar, como implementar soluciones con el fin de proteger los registros de los pacientes o utilizar modelos de machine learning a fin de analizar el historial médico de un paciente y predecir posibles riesgos para la salud.

## 3.2 Red de socios de AWS

La **Red de socios** de AWS (APN) es una comunidad global que utiliza las tecnologías, los programas, la experiencia y las herramientas de AWS con el fin de crear soluciones y servicios para los clientes. Juntos, los socios y AWS brindan soluciones innovadoras, resuelven desafíos técnicos y brindan valor a los clientes.

Puede trabajar con los socios de AWS para crear o utilizar soluciones especializadas que se adapten a sus necesidades empresariales únicas. **Por ejemplo**, una empresa minorista puede usar AWS para alojar su sitio web. Luego, podrían trabajar con un socio de AWS que se especialice en análisis y machine learning avanzados para mejorar la personalización de los clientes en ese sitio web.

También puede convertirse en socio de AWS. Convertirse en socio tiene muchos beneficios, entre los que se incluyen los siguientes:

- **Beneficios de financiación**: a medida que las empresas se unen a la Red de socios de AWS y participan en programas específicos disponibles para los socios de AWS, pueden obtener diversos beneficios de financiación para ayudar a crear, comercializar y vender con AWS.

- **Eventos para socios de AWS**: los eventos para socios de AWS incluyen seminarios web, talleres virtuales y oportunidades de aprendizaje presencial. Puede utilizar los eventos para socios de AWS con el fin de establecer contactos con otros socios, obtener más información sobre las ofertas nuevas o actuales, y colaborar con los expertos de AWS.

- **Training and Certification para socios de AWS**: aproveche las ofertas únicas y centradas en los socios de AWS Training and Certification. Desde la certificación hasta un servicio o un objetivo de aprendizaje específicos, la cartera de formación para socios de AWS ofrece numerosas oportunidades con el fin de mejorar sus conocimientos sobre la nube.
