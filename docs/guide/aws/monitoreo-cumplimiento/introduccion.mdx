# Introducción a la supervisión, el cumplimiento y la gobernanza en la nube de AWS

La **supervisión**, el **cumplimiento** y la **gobernanza** en AWS son componentes fundamentales para administrar un entorno de nube de forma segura, controlada, eficiente y alineada con las políticas de una organización. A medida que aumenta el número de usuarios, cuentas, aplicaciones y recursos en AWS, es necesario contar con mecanismos que permitan saber qué está ocurriendo, verificar que se cumplen las reglas establecidas y mantener un control adecuado sobre la infraestructura.

La **supervisión** (monitoring) permite observar continuamente el comportamiento de los recursos y aplicaciones, recopilar métricas, registros y eventos, y detectar problemas o comportamientos anómalos. 

El **cumplimiento** (compliance) busca garantizar que los recursos y procesos de AWS respeten los requisitos legales, normativos y las políticas internas de la organización. 

Por otro lado, la **gobernanza** (governance) establece las reglas, políticas y controles que determinan cómo debe utilizarse AWS dentro de una organización.

![supervisión, el cumplimiento y la gobernanza en la nube de AWS](/aws/monitoreo/monitoreo-intro.jpg)

En términos simples:

>**Supervisar → Verificar → Controlar → Mejorar**

El objetivo final es conseguir un entorno AWS donde los recursos puedan utilizarse de manera segura y eficiente, manteniendo visibilidad sobre las operaciones, cumpliendo los requisitos establecidos y aplicando políticas de gobierno consistentes en toda la organización.

:::info Recuerda
- **Supervisión** = saber qué está ocurriendo.
- **Cumplimiento** = verificar que se cumplen las reglas.
- **Gobernanza** = establecer y controlar las reglas.

:::

## 1. Supervisión de sus recursos en la nube de AWS

Para supervisar de manera eficaz sus soluciones en la nube de Amazon Web Services (AWS), necesitará formas de brindar información sobre la utilización de los recursos, identificar posibles problemas y facilitar resoluciones proactivas.

La progresión que normalmente se recomienda usar es la siguiente:

1. Proteger los sistemas 
2. Supervisar las actividades 
3. Realizar auditorías
4. Garantizar el cumplimiento 

![Supervisión de sus recursos en la nube de AWS](/aws/monitoreo/monitoreo-supervision-aws.png)
