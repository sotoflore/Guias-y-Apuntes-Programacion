## Conceptos Clave Adicionales

### Tipos de Deployments

| Concepto | Descripción |
|---|---|
| **Blue/Green Deployment** | Dos entornos idénticos, se cambia tráfico de uno a otro |
| **Canary Deployment** | Porcentaje pequeño de tráfico al nuevo version, aumenta gradualmente |
| **Rolling Deployment** | Actualización gradual de instancias en lotes |
| **All-at-Once** | Todas las instancias se actualizan simultáneamente |

### Tipos de Load Balancers

| Tipo | Capa | Latencia | Uso |
|---|---|---|---|
| **ALB** | Layer 7 (HTTP/HTTPS) | ~300ms | Web apps, microservicios |
| **NLB** | Layer 4 (TCP/UDP) | ~100ms | Gaming, IoT, extreme performance |
| **GLB** | Layer 3 (IP) | ~150ms | Protocolos no estándar |
| **CLB** | Layer 4/7 (Legacy) | ~300ms | Aplicaciones legacy |

### Tipos de Storage

| Tipo | Servicio | Acceso | Uso |
|---|---|---|---|
| **Object** | S3 | HTTP/REST | Archivos, backups, static assets |
| **Block** | EBS | SCSI/iSCSI | Volumes EC2, boot volumes |
| **File** | EFS/FSx | NFS/SMB | Shared file systems |
| **Archive** | Glacier | API | Long-term retention |

### Tipos de Bases de Datos

| Tipo | Servicio | Modelo | Caso de Uso |
|---|---|---|---|
| **Relational** | RDS, Aurora | SQL | Transacciones, reporting |
| **NoSQL** | DynamoDB | Key-Value/Document | Apps de alto volumen |
| **In-Memory** | ElastiCache | Cache | Sessions, real-time |
| **Graph** | Neptune | Graph | Social networks, recommendations |
| **Time Series** | Timestream | Series de tiempo | IoT, monitoring |
| **Ledger** | QLDB | Ledger | Auditoría, finanzas |
| **Wide Column** | Keyspace | Cassandra | IoT, time series |
| **Search** | OpenSearch | Full-text | Analytics, logging |

### Conceptos de Seguridad

| Concepto | Descripción |
|---|---|
| **Least Privilege** | Dar solo los permisos necesarios |
| **Defense in Depth** | Múltiples capas de seguridad |
| **Zero Trust** | No confiar en nada por defecto |
| **Encryption at Rest** | Cifrar datos almacenados |
| **Encryption in Transit** | Cifrar datos en movimiento |
| **IAM Role** | Identidad con permisos temporales |
| **Security Group** | Firewall stateful a nivel de instancia |
| **NACL** | Firewall stateless a nivel de subnet |
| **WAF** | Protección contra exploits HTTP |
| **Shield** | Protección DDoS |

### Conceptos de Networking

| Concepto | Descripción |
|---|---|
| **VPC** | Red privada virtual |
| **Subnet** | Subdivisión de red dentro de VPC |
| **Internet Gateway** | Acceso a internet para VPC |
| **NAT Gateway** | Acceso a internet para subnets privadas |
| **VPC Peering** | Conexión entre dos VPCs |
| **Transit Gateway** | Hub central para conectar VPCs |
| **VPC Endpoint** | Acceso privado a servicios AWS |
| **Direct Connect** | Conexión dedicada on-premises |
| **Route 53** | DNS managed |
| **CloudFront** | CDN global |
