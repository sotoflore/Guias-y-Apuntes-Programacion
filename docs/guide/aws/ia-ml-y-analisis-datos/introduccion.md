# Introducción a la IA y al Machine Learning

Desde el comercio electrónico hasta la investigación médica utilizan datos de alta calidad para analizar eventos pasados e innovar para el futuro. La **IA** y el **ML**, por un lado, y el **análisis de datos**, por el otro, son dos campos muy involucrados en estos procesos.

## 1. Inteligencia Artificial

La **inteligencia artificial** es un campo amplio que se centra en el desarrollo de sistemas informáticos inteligentes capaces de realizar tareas similares a las humanas.

![Inteligencia Artificial](/aws/ia-ml/inteligencia-artificial.jpg)

## 2. Machine Learning

El **machine learning** es un tipo de IA que se usa para entrenar a las máquinas con el fin de que estas realicen tareas complejas sin instrucciones explícitas. El entrenamiento del machine learning encuentra los patrones ocultos en grandes cantidades de datos históricos para producir un modelo de ML. Luego, este modelo de ML se puede aplicar a nuevos datos para hacer predicciones o tomar decisiones en función de los patrones que aprendió.
